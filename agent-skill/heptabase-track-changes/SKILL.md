# Heptabase track changes (pointer)

The rules live in the user's Heptabase space, not in this file. This keeps one copy that the Heptabase AI Agent and every connected agent share.

1. List the Heptabase Skills in the user's space (they also appear at the end of the Space Instructions).
2. Find `/track-changes`. Read its instruction card and follow it for this request.
3. If it is missing, tell the user and offer to install it from https://github.com/RTsai1202/heptabase-track-changes by following that repository's INSTALL.md. Do not invent the rules from memory.

When a host skill about Heptabase also applies, use it for how to read and edit content, and use `/track-changes` for how to mark and resolve the changes.
